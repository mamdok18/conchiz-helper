# 콘치즈 도우미

피규어·프라모델 도색용 **도료 조색 도우미** (Windows 프로그램)

이미지에서 원하는 색을 스포이드로 찍으면, 내가 가진 도료만으로 그 색을 만드는 비율(%)과 방울 수를 계산해 줍니다.

## 받기

**[최신 버전 받기 → Releases](https://github.com/mamdok18/conchiz-helper/releases/latest)**

1. `콘치즈도우미.exe` (파일 이름은 `ConchizHelper.exe`로 받아질 수 있어요)를 내려받습니다.
2. 원하는 폴더에 두고 실행합니다. 설치할 필요가 없어요.
3. Windows가 "알 수 없는 게시자" 경고를 띄우면 **추가 정보 → 실행**을 누르세요.

## 주요 기능

- **조색**: 이미지를 열거나 붙여넣고(Ctrl+V) 색을 찍으면 보유 도료로 만드는 비율을 계산
- **보유 도료**: 내 도료 등록, 화면이나 이미지에서 색 찍어 넣기, 그룹 · 메모
- **레시피**: 조색 결과 저장, 그룹 · 태그 · 검색, 끌어서 정리

## 업데이트

켜 두면 **10분마다 새 버전을 확인**합니다. 새 버전이 있으면 윗줄에 **업데이트** 버튼이 생기고, 누르면 바로 적용돼요.

## 데이터

- 도료와 레시피는 `%APPDATA%\ConchizHelper` 폴더에 저장됩니다.
- 윗줄의 ⬇ 내보내기 / ⬆ 불러오기로 백업할 수 있어요.

## 필요한 것

- Windows 10 / 11 (.NET Framework 4는 기본으로 들어 있음)
- [Pretendard](https://github.com/orioncactus/pretendard) 글꼴이 설치되어 있으면 그 글꼴로, 없으면 맑은 고딕으로 보여요.
